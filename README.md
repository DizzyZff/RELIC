# RELIC

> 用一组结构化 Q&A，蒸馏出你自己的 `skills.md`，给模型 Agent 直接使用。

## 项目目标

这个仓库不是训练框架，也不以 LoRA 为核心。  
RELIC 的核心目标是：**把你的经验、偏好和决策方式，整理成一份稳定的 `skills.md`**。

你可以把它理解为一个最小闭环：

1. 通过问答采集你的做事方式
2. 结构化沉淀到 `skills.md`
3. 持续迭代，让 Agent 越来越像你

## 工作流（Q&A 蒸馏）

```text
你（回答问题）
   ↓
Q&A 记录
   ↓
归纳/抽象
   ↓
skills.md（给 Agent 的能力说明书）
```

## 如何使用

### 1) 打开并填写 `skills.md`
从核心身份、能力边界、决策偏好开始，不需要一次写完。

### 2) 用连续 Q&A 补全细节
建议每次聚焦一个主题（如：写作、编码、沟通、决策）。

### 3) 每轮迭代后更新 `skills.md`
把“稳定有效”的回答沉淀成规则，把一次性观点放在备注中。

### 4) 将 `skills.md` 提供给你的 Agent
可直接作为 system prompt 的一部分，或作为长期记忆文件。

## 推荐提问方式（可直接复制）

```text
请作为我的能力访谈助手，连续向我提出 20 个问题。
目标：蒸馏出一个给模型 Agent 使用的 skills.md。
要求：
1) 问题按主题分组：身份、能力、决策、沟通、边界；
2) 每次只问 1 个问题；
3) 当回答抽象时，追问具体案例；
4) 最后输出结构化总结，方便直接回填 skills.md。
```

## 隐私说明

- `skills.md` 可能包含高密度个人偏好信息，请按需脱敏。
- 原始私密资料建议仅本地保存，不上传。
- 本仓库默认忽略 `data/raw/` 与模型权重目录，降低误提交风险。
